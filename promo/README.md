# Печатные макеты

## Реклама приложения на кассовой стойке — А4

`app-a4.html` — исходник макета, `chailand-app-a4.pdf` — то, что отдают в печать.

- Формат А4 (210×297 мм) вертикально, без полей, фон под обрез.
- QR ведёт на `https://lk.chailand.org` — короткий адрес личного кабинета
  (Caddy переадресует его на `/lk/`). Зона тишины вокруг кода — 4 модуля,
  как требует стандарт: без неё телефон читает код хуже.
- Шрифт Montserrat вшит в файл, логотип берётся из `../logo.png`.

### Перегенерировать

Поменяли текст или адрес — правьте `app-a4.html` и соберите заново:

```
node promo/render.js promo/app-a4.html promo/chailand-app-a4
```

Новый QR (если сменится адрес):

```
node -e "require('qrcode').toString('https://lk.chailand.org',
  {type:'svg',errorCorrectionLevel:'H',margin:4}).then(console.log)"
```

`errorCorrectionLevel:'H'` — код читается, даже если его частично затёрли
или заклеили; `margin:4` — та самая зона тишины.

### Печать

Печатать «как есть», без масштабирования («100 %», не «вписать в страницу»),
на плотной бумаге от 150 г/м². Проверьте, что принтер не отрезает фон по краям.
