# Чайлэнд — Админ-панель / POS (демо)

Единый HTML-прототип админ-панели парка развлечений «Чайлэнд».

- `index.html` — всё приложение в одном файле (данные в памяти браузера, демо).

## Разделы
- **Касса** — смена, тарифы по дню недели, чек, оплата (наличные/карта/онлайн), списание и начисление бонусов, эмуляция фискализации (Штрих-М), продажи за смену, возвраты.
- **Праздники** — бронирование банкетных комнат и услуг (аниматоры, шоу, фотозона…), предоплата, статусы.
- **Клиенты** — база клиентов, выдача карт (GAB-xxxx), бонусы.
- **Отчёты** — выручка, оплаты, расходы, закрытие смены (Z-отчёт).
- **Настройки** — тарифы, услуги праздника, комнаты, кэшбэк, праздничные даты.
- **Роли** — Владелец / Администратор / Кассир (демо-переключение).

## Просмотр
Откройте `index.html` в браузере — сборка не требуется.
